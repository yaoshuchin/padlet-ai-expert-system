## ⚡ 核心功能與互動體驗

1. **三種檢視視圖**：
   - **瀑布流看板 (Masonry)**：還原 Padlet 風格的瀑布流版面。
   - **標準網格 (Grid)**：現代卡片佈局，適合大螢幕多欄比對。
   - **清單條列 (List)**：緊湊行列表，便於快速搜尋與批次查找。
2. **多維即時篩選**：
   - 支援依「平台（Edcafe AI / Poe / ChatGPT 等）」與「領域（體育 / 閱讀 / 思辨等）」即時交集過濾。
   - 即時關鍵字搜尋：按鍵盤 `/` 鍵即可快速定位搜尋列。
3. **一鍵複製與快捷跳轉**：
   - 點擊「複製網址」即可寫入系統剪貼簿。
   - 點擊「前往試聊」新分頁直通 Edcafe AI 或 Poe 機器人。
4. **隨機抽籤 (Sparkles)**：
   - 點擊頂部「🎲 隨機抽籤」，系統即刻挑選一位 AI 專家跳出互動卡片，適合課堂破冰或備課靈感探索！
5. **匯出 CSV 報表**：
   - 支援一鍵將目前篩選之專家清單匯出為 UTF-8 with BOM 的 CSV，可直接以 Microsoft Excel 開啟且絕不亂碼。
6. **深色 / 淺色模式切換**：
   - 內建優雅深色系與明亮清新雙色主題。

## 🚀 快速開啟方式

- **方式 1（直接點開）**：直接雙擊 [**`start.bat`**](./start.bat) 或以瀏覽器直接開啟 [**`index.html`**](./index.html)。
- **方式 2（本機靜態伺服器）**：
  ```bash
  npx serve .
  # 或使用 Python
  python -m http.server 8080
  ```

## 🌐 線上部署 (GitHub Pages & Netlify)

### GitHub Pages
1. 本專案已推播至 GitHub 倉庫：`https://github.com/yaoshuchin/padlet-ai-expert-system`
2. 進入倉庫 **Settings** -> **Pages**
3. **Build and deployment** 來源選擇 **Deploy from a branch**
4. Branch 選擇 `master`（或 `main`），目錄選擇 `/ (root)`，點擊 **Save**。
5. 發布後即可於 `https://yaoshuchin.github.io/padlet-ai-expert-system/` 線上瀏覽。
